# 更新日志

本文件记录 `dsh-node-monitor` 的功能、修复与安全变更。版本号遵循 SemVer；插件宿主半更新后需要重启 DSH，客户端半刷新页面即可生效。

## v0.6.3 — 2026-11-12（安全审核）

**安全修复**
- 新增只读令牌 `statusToken`：自动配对与自动组网只交换只读令牌；只读令牌可读看板级状态（会话明细与最近事件被清空、控制强制关闭），不能调用 `/control`。
- 删除「自动配对时隐式开启运维控制」的逻辑，`allowControl` 恢复默认关闭。
- Hub 控制命令带 `expiresAt`（20s），超时后移出队列；队列上限 10，避免节点重连后执行过期操作。
- `hubPeers` 上限 128、7 天过期；同一 `nodeId` 60 秒内更换来源 IP 返回 409 `peer-conflict`。
- 请求体读取 20 秒超时；`audit.jsonl` 超过 5MB 自动轮转为 `.1`。
- 复制按钮增加 `execCommand` 回退，HTTP 局域网与非安全上下文可用。
- 接入码增加「含令牌等同密码」风险提示；自动接入节点在详情页显示只读提示。

**测试**：30 单测 + 18 集成 = 48。

## v0.6.2 — 2026-11-12（无服务器接入码 + IPv6 双栈）

- 新增「接入码」：`http://<地址>/#node-monitor-add=<base64url({v,u,t})>`，一条链接/二维码完成添加节点；粘贴到「节点地址」自动填地址与令牌。
- agent 服务改为双栈监听 `::`（失败回退 `0.0.0.0`），同时承载 status / control / pair / hub 端点；IPv6 与 Tailscale/ZeroTier 地址可直接作为 `baseUrl`。
- 新增宿主 RPC `nodeInvite`，枚举本机非回环 IPv4/IPv6 地址。
- 跨网 Hub 场景可直接把主节点地址填 `http://<虚拟IP>:45873`，绕过 DSH 的登录与 Host 校验。
- 测试：45 → 48（随 v0.6.3 一并统计）。

## v0.6.1 — 2026-11-12（加入链接与二维码）

- Hub 面板新增「复制加入链接」「二维码」：链接形如 `<origin>/#node-monitor-join=<token>`，令牌只放在 `#` 片段，不发送给服务器、不写入日志；页面读取后立即 `history.replaceState` 清除。
- 二维码由宿主内置 `lib/qrcode.js`（qrcode-generator 2.0.4，MIT）本地生成 SVG，不经过第三方服务。
- 客户端在「主节点地址」粘贴整条链接会自动拆出地址与令牌。
- 新增 `config.publicUrl` / `DSH_NODE_MONITOR_PUBLIC_URL`，反代部署时用于生成正确的对外地址。
- 测试：43。

## v0.6.0 — 2026-11-12（远程主节点 / 跨网反连）

- 服务器 DSH 可作为 Hub：PC 每 3 秒向 `/node-monitor/api/v1/hub/push` 上报状态并取回排队指令，无需公网 IP、端口映射或 VPN。
- Hub 把 PC 投影为 `hub:<nodeId>`、`adapter=hub`、标签「远程」的节点，复用总览、告警、筛选与批量。
- 控制指令经 Hub 队列下发、PC 执行后回传结果并写审计；支持 `plugins.list` / `plugins.setEnabled`，不支持远程重启。
- 加入令牌 12 位、可旋转；令牌只在 `hubInfo` 显式请求时返回，不进入 state。
- 测试：41。

## v0.5.0 — 2026-11-12（局域网零配置组网）

- 插件自监听 `0.0.0.0:45873`，不再要求 DSH `--host` 或开放 3081。
- UDP 发现报文携带 agent 端口；发现后自动向对方 `/pair` 登记并交换只读令牌，双方自动互加（`tags=paired,auto`）。
- 自动接入节点默认只读；界面标签「自动」「双向」；对无 DSH 登录令牌的节点隐藏「打开/内嵌」。
- 测试：40。

## v0.4.1 — 2026-11-12（名称自动与双向配对）

- 添加节点时名称可留空，宿主用远端 `/status` 的 hostname 自动补全，失败回退地址。
- 双向配对：添加节点后自动向对端登记，对端按来源 IP + 端口自动添加回本机。
- 测试：40。

## v0.4.0 — 2026-11-12（局域网自动发现）

- UDP 45871 组播（239.255.43.21）+ 广播，30 秒一次；只广播 id/名称/端口/版本，不含令牌。
- 本机配对信息：节点 ID、显示名、12 位连接令牌（掩码/复制/轮换）。
- 发现列表一键「接入」预填地址；接入仍需对方令牌校验。
- 测试：38。

## v0.3.0 — 2026-11-12（H1–H4）

- H1 只读会话概览（ID/状态/模型/工作目录/最近活动，不读取会话正文）。
- H2 同源内嵌：同主机名时用 iframe 嵌入远端 DSH，跨站自动降级提示新标签打开。
- H3 运维控制：默认关闭，需 `allowControl` / `allowRestart` 显式开启；dry-run、二次确认、JSONL 审计。
- H4 筛选（关键字/状态/分组）、告警「打开节点」深链、分组标签。
- 测试：32。

## v0.1.1 — 2026-11-12（加载安全）
