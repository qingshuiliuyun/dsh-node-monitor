## v0.6.8 — 2026-11-15（浏览器跨站请求防护）

- 所有会改变状态的 HTTP 路由（pair/control/hub push/hub result）新增两道门：

## v0.6.6 — 2026-11-12（健壮性复审）

**安全与健壮性**
- 自动配对增加独立限流（每 IP 12 次/分钟、60 次/小时）与自动节点上限 16，防止同网段刷节点列表。
- Hub 控制结果必须由对应 `nodeId` 回传，否则返回 403 `peer-mismatch`，避免命令结果被其他客户端顶替。
- `publicUrl` 仅接受 http/https，非法值回退到本机 origin；加入/接入链接在客户端校验协议、hostname 与令牌长度。
- 二维码 SVG 增加白名单校验（必须以 `<svg` 开头、拒绝 script/事件属性/javascript:）后再写入 DOM。
- 请求/认证计数表、Hub peer、命令队列定期清理，避免长时间运行内存增长。

**测试**：30 单测 + 20 集成 = 50。

## v0.6.3 — 2026-11-12（安全审核）

**安全修复**
- 新增只读令牌 `statusToken`：自动配对与自动组网只交换只读令牌；只读令牌可读看板级状态（会话明细与最近事件被清空、控制强制关闭），不能调用 `/control`。
- 删除「自动配对时隐式开启运维控制」的逻辑，`allowControl` 恢复默认关闭。
- Hub 控制命令带 `expiresAt`（20s），超时后移出队列；队列上限 10，避免节点重连后执行过期操作。
- `hubPeers` 上限 128、7 天过期；同一 `nodeId` 60 秒内更换来源 IP 返回 409 `peer-conflict`。
- 请求体读取 20 秒超时；`audit.jsonl` 超过 5MB 自动轮转为 `.1`。
- 复制按钮增加 `execCommand` 回退，HTTP 局域网与非安全上下文可用。
- 接入码增加「含令牌等同密码」风险提示；自动接入节点在详情页显示只读提示。

**测试**：30 单测 + 18 集成 = 48。
